# Puls 180 – Das Blutdruck- & Puls-Tagebuch

Puls 180 sammelt Blutdruck und Puls übersichtlich auf dem Android-Handy. Die App bietet einen großen Hand-Knopf zur Handeingabe, Health Connect, geeignete Bluetooth-Messgeräte, Sprachansage, Monatsübersichten sowie PDF-, Excel- und CSV-Export.

## Downloads

- [Puls 180 Version 5.14 herunterladen](https://raw.githubusercontent.com/Kubihl/blutdruck-for-user/main/Puls-180-5.14.apk)
- [PC-Tagebuch für vier Benutzer herunterladen](https://raw.githubusercontent.com/Kubihl/blutdruck-for-user/main/Puls-180-PC-Tagebuch-5.9.zip)

PC-Werte können als JSON-Datei gespeichert und bei direktem Kopieren per USB übertragen werden. Über „PC-Datei senden an …“ lässt sich die Datei auch an eine gewählte App weitergeben; danach wird sie am PC importiert.

Puls 180 unterstützt Android 10 und neuer. Health Connect steht ab Android 14 zur Verfügung; Handeingabe und geeignete Bluetooth-Messgeräte funktionieren auch auf älteren unterstützten Android-Versionen.

Beim ersten Öffnen ist die App vierzehn Tage vollständig freigeschaltet. Danach wird für die dauerhafte Nutzung ein passender, gerätegebundener Kaufschlüssel benötigt. Neue Schlüssel können nach einer Neuinstallation auf demselben Handy erneut verwendet werden.

Puls 180 ist ein privat entwickeltes Hobbyprojekt zur persönlichen Dokumentation. Die App misst keinen Blutdruck, stellt keine Diagnose, gibt keine Therapie- oder Medikamentenempfehlungen und ersetzt keine ärztliche Beratung.
