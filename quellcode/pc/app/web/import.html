Handywerte als Datei importieren

Zuerst PC-Benutzer bearbeiten. Der Name muss mit dem Namen auf dem Handy übereinstimmen.

Übertrage die gespeicherte JSON-Datei zum Beispiel per USB-Kabel vom Handy auf den PC. Wähle dann die Messwert-Datei aus Puls 180. Prüfe vor dem Import den Namen und den Zielbenutzer. Bereits vorhandene Werte werden anhand ihrer Kennung nicht doppelt angelegt. Die Datei löscht keine Werte. Eine Datei ist eine einmalige Übergabe: spätere Löschungen auf dem Handy werden damit nicht automatisch übertragen.
